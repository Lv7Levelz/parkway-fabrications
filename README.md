## SEO
The site contains Sheffield/industry-specific titles, descriptions, heading architecture and LocalBusiness schema.  
**Demo safety:** every page currently includes `noindex,nofollow` and `robots.txt` blocks crawling so this concept does not compete with the client's existing live website.

Before production handover:
1. Remove the `noindex,nofollow` meta tags.
2. Change `robots.txt` to `Allow: /`.
3. Replace example sitemap URLs with the production domain.
4. Add canonical URLs to the production domain.
5. Connect the client's approved form backend and email address.
6. Replace/augment the custom SVG visuals with the client's original high-resolution photography once supplied/approved.
7. Verify all claims, certifications and current trading/contact details with Parkway before launch.

## Source note
Business/service information was reconstructed from publicly indexed Parkway Fabrications website content and public business listings.
